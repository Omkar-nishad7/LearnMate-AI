# Contributing to LearnMate AI

Thanks for considering a contribution.

## Before you start

1. Open an issue describing the bug or proposed change.
2. For substantial changes, discuss the design before opening a pull request.
3. Never include secrets, real student data, production database dumps, or uploaded user files.

## Development workflow

1. Fork the repository and create a focused branch.
2. Follow the setup steps in `README.md`.
3. Keep changes limited to the issue being addressed.
4. Add or update tests for behavior changes.
5. Run relevant backend tests and the frontend production build.
6. Update documentation and environment templates if configuration changes.
7. Open a pull request with a clear summary, testing evidence, and screenshots for UI changes.

## Pull request checklist

- [ ] The change is scoped and documented.
- [ ] No credentials or private data are included.
- [ ] Tests were added/updated where appropriate.
- [ ] Database migrations are backward-aware and included when required.
- [ ] Existing student/teacher workflows are not unintentionally broken.
